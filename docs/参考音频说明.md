# 参考音频说明

`新传真通知.WAV` 是用户本机提供的约 4.18 秒参考片段，44.1 kHz、16 位、双声道；它不是已经克隆完成的音色，也不是来电铃声。准确日语台词未知，注册到 Qwen TTS WebUI 时请让 `ref_text` 保持空值，切勿猜填。

这段音频比教程建议的 5–15 秒略短，若伴随音效、背景音乐或压缩失真，克隆效果可能不稳定。先独立试听合成结果；相似度不佳时，换成更干净、更长且已获许可的人声重新注册，不要仅改 Amadeus 里的音色 ID。

用户提供的 [《牧濑红莉栖提示音》原发布页](https://www.bilibili.com/video/BV1gHVd6CEyE/) 在简介中给出 [原发布者的分享入口](https://pan.quark.cn/s/c8695a0c8fe3)，并声明分享内容免费、音频仅供学习且不得商用。用户本机的 `新传真通知.WAV` 尚未与原分享文件逐字节比对；文件名和主题相似不能代替来源核验。

该声明没有明确允许第三方重新打包分发，也没有明确允许用录音制作可供其他用户使用的克隆声线。项目的公开发行 ZIP 因此不携带此文件，也不会把作者本机的克隆音色、API Key 或用户数据交给安装者。需要这套提示音的用户应从原发布入口自行获取，并遵守发布者的用途限制；不要把“可以免费下载学习”理解为“可以并入别人的发行包”。

若你持有可用于参考克隆的音频授权，按根目录 [使用教程](../使用教程.md#33-注册自己的参考音频) 注册 WAV，取得自己的音色 ID。复制 WAV 到 Amadeus 目录本身不会生成可朗读的新声线。
