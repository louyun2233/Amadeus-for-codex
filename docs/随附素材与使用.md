# v1.0.0 随附素材与使用

发行包和仓库的 `assets/media` 包含以下运行素材，`catalog.json` 登记每个文件的相对路径、大小和 SHA-256：

| 类别 | 内容 |
| --- | --- |
| 新角色 | 常服、实验服、女仆、泳装、浴衣五套，包含 MOC3、贴图、12 种表情、动作和物理文件 |
| BGM | 14 首，可在「设置 → 角色素材 → 音乐曲目」选择 |
| 背景 | 8 张场景，可在「人物背景」选择，也可导入自己的图片 |
| 来电 | bgm13 的 MP3 副本，使用独立铃声通道，接听或拒接即停 |

新安装默认使用原 Live2D、黑色背景和音量 12% 的 bgm10。五套新角色安装后直接可选，均支持正常／大头取景。它们保持原始头身姿态，提供瞳孔跟随、眨眼、眉眼、口型、表情、呼吸与发束绑定，不提供真实左右转头的透视。

## 安装与升级

完整解压安装包，双击 `安装 Amadeus.cmd`。原生依赖安装完成后，安装器校验素材并复制到 `%USERPROFILE%\.amadeus\media`。直接运行新版面板也会补齐素材。显式配置 `AMADEUS_MEDIA_DIR` 时使用该目录，配置 `AMADEUS_DATA_DIR` 时使用其中的 `media`。

素材库与安装目录分开，关闭重开或更新程序不会丢失选择。已有安装保留当前角色、取景、背景、音乐开关、音量和铃声。发行包管理的文件升级前保存旧文件；用户自行改过的音乐和图片保留，模型中任一文件被自行修改时保留整套模型，避免混合不同版本的网格和贴图。缺失文件可在重新安装时补齐。

校验失败时先重新下载、完整解压，不能只修改 `catalog.json` 来跳过校验。自行制作或修改角色时，在自己的媒体目录保存运行文件，并按[角色替换教程](角色替换教程.md)或[模型说明](音乐背景与角色建模.md)配置。PSD、PSD2Live/Cubism 编辑工程和建模工具不在此素材包内。
