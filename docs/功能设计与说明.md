# 功能设计与说明

本文说明当前 Amadeus for Codex 的功能、运行流程和设计边界。安装、音色克隆与源文件换角色的逐步操作分别见 [安装说明](INSTALL.md)、[使用教程](../使用教程.md) 和 [角色替换教程](角色替换教程.md)；默认值以 [`config/defaults.json`](../config/defaults.json) 为准。

## 1. 产品定位

Amadeus 是运行在用户电脑上的 Codex 伴侣，而不是独立的在线聊天账号。它用翻盖手机面板承载对话、Live2D、语音、记忆与主动互动；Codex 任务通知也可进入同一面板。默认对话使用用户自己的 Codex 登录；音色、云端密钥和参考音频由用户自行配置。

设计上保持三条界限：角色说话与来电铃声分开；选中克隆音色后不静默换成其他声线；主动功能和长期记忆由用户明确开启。

角色身份不设页面切换器：`config/defaults.json` 选角色与默认声线，`persona/<id>.md` 写对话人设，`persona/<id>.json` 写显示名与开场白、点击、任务、来电及闲聊兜底台词，`config/assets.registry.json` 登记模型及动作/表情映射。已有本机配置需在停机后运行 `npm run character:apply` 才会采用新的源码默认值；该命令备份原配置，保留其他设置。缺文件时显式失败，不回退到红莉栖台词。

## 2. 功能总览

| 功能 | 当前行为 | 新安装默认 | 主要入口 |
| --- | --- | --- | --- |
| 启动与面板 | Codex 守候程序检测到 Codex 后打开独立窗口；也可双击 `Amadeus.exe` 或用 CLI 手动打开 | 安装时启用守候，可用 `-NoAutoStart` 关闭 | `bin/amadeus-watch.mjs`、`bin/amadeus-panel.mjs` |
| 开场白 | 新一轮连携打开面板或单独打开新面板时请求一次；刷新、重连不重复 | 仅语音已启用时播放 | `src/panel/main.js` |
| 对话 | 发送文本、显示回复、可取消生成；默认单句模式，每轮结束断开上下文 | `codex-exec`、单句模式 | `src/core/chat.mjs`、`src/host/chat-routes.mjs` |
| 语音合成 | 回答、点击反应、开场白、接听后的台词和任务播报共用当前选中的语音通道 | 语音关闭 | `src/core/tts.mjs`、`src/panel/audio-queue.js` |
| 角色表现 | Live2D 表情、头部与视线随情绪标签变化；点击时轮换动作片段 | 减少动态效果设置生效 | `src/panel/live2d.js`、`src/panel/affect.js` |
| 来电 | 先显示来电界面并播放独立铃声；接听后停止铃声再说台词；拒接不念台词 | 主动来电关闭 | `src/core/scheduler.mjs`、`src/panel/ringtone.js` |
| Codex 任务播报 | 可播报任务开始、完成、失败；同类台词轮换，内部辅助任务不单独播报 | 关闭 | `bin/amadeus-notify.mjs`、`src/core/task-lines.mjs` |
| 长期记忆 | 可手动记录、检索、导出、遗忘与清空；可选自动提取长期事实 | 记忆与自动提取均关闭 | `src/core/memory.mjs`、`src/host/memory-routes.mjs` |
| 主动闲聊 | 空闲达到阈值、面板在线且当前没有对话时才考虑开口 | 关闭 | `src/core/scheduler.mjs` |
| 语音输入 | 浏览器识别、Whisper 兼容接口或关闭麦克风 | 浏览器识别 | `src/core/stt.mjs`、面板设置 |
| 自检 | 展示模型、语音、素材和运行状态；CLI 可执行 `doctor` | 可随时使用 | `src/core/diag.mjs`、`bin/amadeus.mjs` |

首次打开面板会出现两步使用引导：先说明数据流向，再选择语音、任务播报、记忆、闲聊和来电。跳过引导不会自动开启这些可选功能。

## 3. 运行结构与主要流程

```text
Codex / Amadeus.exe / CLI
        │
        ├─ watcher 与 panel launcher ──> 独立面板窗口
        │                                 │
        └─ MCP / notify ────────────────> 本机 daemon (127.0.0.1)
                                          ├─ 对话、会话、记忆
                                          ├─ 语音合成与识别
                                          ├─ 来电、任务事件
                                          └─ 配置、密钥、缓存、诊断
```

daemon 只监听本机地址。面板通过本机 HTTP 接口提交请求，通过事件流接收新消息、任务播报和来电；面板入口用一次性 token 换取会话 cookie。运行时 token 是本机访问凭据，不能和安装目录一起分享。`bin/` 是启动入口，`src/core/` 放业务规则，`src/host/` 负责本机服务与适配，`src/panel/` 负责界面、动画与播放。

### 对话流程

1. 面板提交文本，daemon 选用或创建会话并立即返回本轮 `turnId`。
2. 对话引擎按配置召回记忆、构造角色上下文、调用所选模型通道，再解析回复中的日语、中文与情绪。
3. 面板逐步显示回复，并把需要朗读的日语交给当前语音合成器；情绪同时驱动 Live2D。用户可在生成中取消本轮。
4. 单句模式下，本轮结束后会话断开。长期记忆的自动提取只有在记忆和自动提取都开启时才执行。

### 语音与音色一致性

声音的来源由「设置 → 音色」决定。安装包不附带任何人的克隆音频或克隆 ID：本地克隆须先在 Qwen TTS WebUI 注册参考音频，再导入该服务返回的 ID；阿里云克隆须使用相应账号的云端音色 ID。两种 ID 不通用。详细步骤见 [使用教程](../使用教程.md#3-从零制作本地克隆音色)。

选择 `qwen-local` 时，合成器忽略单次请求传入的其他音色名，统一使用已选本地音色；服务不可用时明确报错，不会让 Edge 或系统语音冒充角色。阿里云自定义音色在「保持音色一致」开启时失败也会报错；只有用户关闭该设置后才允许退回 Edge。未配置云端密钥的内置默认音色可以使用 Edge，但这不代表克隆成功。

音频缓存按文本、音色、提供方和情绪等参数区分。本地克隆可输出 WAV；当前本地 Base 克隆没有显式的情绪韵律控制，面部表情与台词情绪不等于声学情绪已经改变。为保持相似度，不对克隆结果强行变调或改音色。Live2D 模型自带的原版语音片段不会自动播放。

### 来电与任务播报

来电铃声是独立提示音，不是角色人声。优先读取用户放在数据目录 `sounds/incoming.wav` 等受支持格式的文件；没有时尝试系统提示音。铃声失败不应改变接听后的语音来源，面板会显示相应状态。接听时先停铃声再念来电台词；拒接只关闭来电。

Codex 的任务边界由 notify 与守候逻辑送到 daemon。启用播报后，开始、完成、失败各有多句短台词轮换；面板自身发起的对话和内部嵌套任务会被过滤，避免重复或互相打断。选中本地克隆音色时，面板外的「系统播报」不用于代替克隆声线；想听到该声线，需要面板与本地语音服务可用。

### 主动行为与记忆

主动来电和空闲闲聊分别控制，默认都关闭。调度器要求面板在线、没有正在进行的对话，并限制两次主动发声的间隔；长时间休眠后不会补播一串错过的台词。生成失败可改用预置短句，但仍受开关与播放能力约束。

长期记忆分为 `panel`（面板对话提取）和 `codex`（Agent 明确写入）两个命名空间，避免两种来源混杂。记忆可以查看来源、删除或导出；若内容有误，可删除后重新记录。关闭记忆不会删除已保存的内容；需要移除时应使用删除或清空功能。

## 4. 配置、数据与隐私边界

Windows 默认数据目录为 `%LOCALAPPDATA%\Amadeus`，可通过 `AMADEUS_DATA_DIR` 覆盖。配置、会话、记忆、音色登记、铃声、语音缓存、审计与运行状态都属于**用户本机数据**，不属于可分享的发行文件。`runtime/daemon.json` 含本机端口与 token；`secrets.json` 可能含经 Windows DPAPI 保护的密钥，均不可公开。审计和诊断信息也可能包含操作摘要或本机路径，分享前应单独检查。

| 数据 | 可能到达的位置 |
| --- | --- |
| 聊天文本 | 默认经本机 Codex CLI；最终模型服务取决于用户自己的 Codex 配置 |
| 合成文本 | 语音开启后送往当前所选 TTS；本地 Qwen 走本机接口，阿里云等提供方会走相应服务 |
| 麦克风音频 | 默认交给浏览器识别，浏览器可能使用在线服务；API 模式送往用户配置的转写接口 |
| 会话、记忆、铃声与语音缓存 | 保存在用户的数据目录，不随发行包打包 |

经过检查的发行包不含作者的 API Key、会话、记忆、录音或克隆样本。这个结论仅针对当前构建产物，不是对以后版本、用户自行加入的文件或第三方服务作绝对保证。分享时只使用 `npm run dist` 生成的 ZIP；不要直接压缩开发目录或 `%LOCALAPPDATA%\Amadeus`。发布前运行 `npm run check`，打包时还会再次执行敏感文件扫描。

## 5. 设计约束与已知限制

- 安装本体只要求 Node.js 22+；本地克隆另需独立安装并启动 Qwen TTS WebUI。安装器不会替用户创建云端克隆音色，也不会附带参考音频。
- 当前的情绪功能主要是台词标签到面部表情、动作和视线的映射；是否具备语音韵律情绪取决于选中的合成模型，不能把表情变化当作声学效果保证。
- 来电铃声与角色说话属于不同通道。角色语音必须经过统一 TTS；提示音不应被误认为克隆声线。
- 本机服务不是公开网站。不要把 daemon 端口、运行时 token 或用户数据目录暴露到公网或纳入分享包。
- 角色模型、语音样本和音效还受原权利方许可约束；代码许可见根目录 [`LICENSE`](../LICENSE) 与 [`NOTICE`](../NOTICE)。

## 6. 验证与维护

修改功能时，至少运行 `npm run check`；修改分发文件后再运行 `npm run dist` 并分享新生成的 ZIP。安装器流程可用 `powershell -ExecutionPolicy Bypass -File scripts\verify-install.ps1` 在隔离配置中验证。面板实际可用性可用 `node bin/amadeus.mjs doctor` 检查；语音、麦克风和云端服务还需在目标电脑上试听与授权，自动测试不能替代真人确认音色相似度。
