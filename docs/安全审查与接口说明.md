# 安全审查与接口说明

审查日期：2026-11-05。范围：当前原生客户端、Node 服务、CLI/MCP/通知入口、安装与打包脚本，以及本地 Git 中可达的文本历史。本次按维护者要求作为 v1.0.0 的同版本安全更新，替换原发行包并同步源码与标签，不修改版本号；已下载旧包的用户需要重新下载并校验新的 SHA-256。

## 已清理的入口和代码

| 清理项 | 原因与当前行为 |
| --- | --- |
| 查询令牌换 Cookie、Cookie 会话 | 原生窗口不需要网页登录。HTTP 服务只接受请求头 Bearer，带 `token` 查询参数的 HTTP 请求被拒绝。启动器传给原生程序的地址通过标准输入读取，不是网页访问，也不会写进进程参数。 |
| `GET /amadeus/voices`、`POST /amadeus/voices/import`、`POST /amadeus/voices/remove` | 旧网页的音色库管理接口没有原生调用，已删除。保留实际合成通道与源文件中的声线配置，不触碰已选克隆声线。 |
| `POST /amadeus/stt` | 原生端使用 Windows 语音识别，已删除旧录音上传、转发与浏览器识别分支；不再提供 STT API Key 或 Whisper 模型设置。旧加密文件中的条目不会因此被删除。 |
| `GET /amadeus/sound/media` | 旧角色原声片段没有合法运行调用，已删除；来电铃声与当前克隆合成仍保留。 |
| `POST /amadeus/proactive/tick` | 删除没有正式客户端调用的强制调度入口；保留正常调度与状态查询。 |
| `POST /amadeus/sessions`、会话重命名/删除接口 | 原生聊天会自行创建会话，没有独立管理调用。保留列表、历史读取、对话发起和取消。 |
| `/amadeus/assets/current/*`、`/amadeus/assets/runtime/*` | 原生 SDK 直接加载模型，不需要 HTTP 静态文件代理；已删除代理和浏览器 JS 运行时安装分支。 |
| `src/panel/`、`scripts/ui/`、`scripts/webview2/` | 删除旧网页、Pixi 库、WebView2 DLL 与浏览器验收脚本；对应网页测试改由原生接口契约和实际本地 HTTP 测试覆盖。 |
| 原生启动中的预览/截图/定时退出环境开关 | 删除假聊天、假来电和任意路径截图等演示分支；正常启动入口不再执行这些一次性设计代码。 |

已删除本地旧发行阶段的发布、媒体导出辅助脚本；可重复使用的安装器、回归测试、建模工程和维护工具保留。`docs/STATUS.md` 是历史开发记录，其中旧网页路径不代表现行功能。

## 当前保留的 HTTP 接口

以下接口全部需要本地连接与 Bearer 认证。保留依据包括原生窗口、CLI、MCP 与任务通知的实际调用；不能仅因某接口不在界面上显示就删除它。

| `GET /amadeus/chat`、`POST /amadeus/chat`、`POST /amadeus/chat/cancel` | 原生发起、跟踪与取消对话；检查发起窗口归属 |
| `GET /amadeus/events` | 原生 SSE 事件连接；认证在请求头中 |

| `POST /amadeus/action` | CLI 停止服务、原生清空播放队列与连通检查；未知命令被拒绝 |

## 本机、账号与 API 的权限边界

1. **监听与认证**：Amadeus 固定监听 `127.0.0.1`；本次检查中 Qwen 也仅监听 `127.0.0.1:7860`。服务同时检查 TCP 来源、Host 与端口，拒绝 Origin、Sec-Fetch-Site、Cookie 登录和 URL 令牌认证。没有通用文件读取、远程命令执行或任意 URL 转发路由。
2. **本地传输**：Node 客户端、本地语音请求、原生 HTTP 与 SSE 绕过系统代理；不跟随重定向，避免认证头被送到其他服务。可选云端模型 API 禁止外部明文 HTTP、URL 用户名/密码和重定向；本机 HTTP API 使用直接连接。
3. **聊天子进程**：保留自己的 Codex 登录及模型供应商配置；每次调用设置只读沙箱、独立空目录和临时会话，关闭 shell、图片读取工具、网页搜索、电脑/浏览器操作、应用、插件、MCP、代码执行宿主、生成图片、记忆工具、通知命令和执行钩子。用户主动附加的图片仍可作为模型输入。无法可靠枚举 MCP 配置时停止调用，不带着未知权限继续。这里是逐次传参，不修改用户全局 Codex 配置。
4. **密钥与日志**：持久密钥继续使用 Windows 用户级 DPAPI；接口只显示配置状态。日志、客户端故障和对话错误共同执行脱敏，完整遮盖已覆盖格式的 API/GitHub/阿里云等凭据、路径和邮箱，不保留密钥首尾片段；无法安全序列化时输出占位文字。
5. **打包**：分发清单排除配置、长期记忆、克隆参考、录音、运行日志、建模工程和本机工具。只有素材目录中已登记且哈希匹配的公开模型/BGM/背景可进入发行包；其余素材不能借此自动进入。

隔离选项参考 OpenAI 的 [Codex 安全说明](https://developers.openai.com/codex/security)、[配置参考](https://developers.openai.com/codex/config-reference) 与 [CLI 参考](https://developers.openai.com/codex/cli/reference)，并在本机安装的 CLI 上验证。

## 检查结果与复查

- 请求边界测试实际启动本地 HTTP 服务，验证无认证、Cookie、查询令牌、网页来源和伪造 Host 被拒绝；已删除接口返回 404，未修改配置或触发调度。
- Node 与 Python 使用本地模拟代理和重定向目标，验证这些目标收不到本地 Bearer；测试不使用真实账号或录音。
- 实际 Codex 配置包含 3 个 MCP，隔离后启用数为 0；所列能力开关均被关闭，真实聊天连接测试正常返回。
- 本次修改前的本地可达 Git 历史共 574 个对象，其中 388 个文本版本进入扫描，未检出既有规则能识别的密钥或个人信息。源码与分发目录另行执行隐私门禁。
- 检查的 7 份个人数据/配置文件没有对 Everyone、Authenticated Users 或普通 Users 组授予读取权限；另以修改前后的文件哈希检查保护数据。
- 完整回归已通过：396 项 Node 测试通过，1 项缺少本地归档的测试按条件跳过；183 项 Windows 原生测试通过。完整验证命令为 `npm run check`，包括 Node 契约/单元测试、已安装的 Windows 原生 Qt 测试和源码隐私检查。`node scripts/make-dist.mjs --out <检查目录>` 会为打包内容再执行严格门禁。

这些结果不是“绝对不会泄露”的保证。当前审查未发现硬编码作者凭据或将账号数据发送到无关服务器的代码；它不是对所有第三方二进制依赖的完整漏洞审计。已登录同一 Windows 用户的恶意程序仍可能读取运行令牌、调用本地服务或在用户权限下读取文件；DPAPI 不隔离同一账号下的进程。切换到云端模型/语音时，提问、用户附加图片、选用的记忆上下文或朗读文本会按功能交给相应服务商。仅公开源码不会自动开放自己的本机端口，也不会把自己的登录授权给下载者。
