# 在源文件中替换角色：模型、人设与声线

本教程适用于想把 Amadeus 做成**另一个角色**的用户。角色不是在面板中一键切换的：改动项目源文件后，先校验，再重启服务。面板仍可调整一般使用选项，但角色身份、固定台词、模型注册和默认声线以源文件为准。

以下以角色 ID `mycharacter` 为例。只使用你有权使用的模型、人物设定、录音及音色；发行包**不包含**克隆样本或角色模型二进制。

## 0. 找到正确的项目目录

在包含 `package.json`、`bin/`、`config/` 的 Amadeus 安装或源码目录打开 PowerShell。若你是通过 Codex 插件安装的，应修改**实际运行的插件副本**，而不只是下载目录；若之后重新安装插件，记得把定制的源文件一并带入新副本。

先备份将要修改的 `config/defaults.json`、`config/assets.registry.json` 和 `persona/`。不要把 `%LOCALAPPDATA%\Amadeus`、API Key、私人参考音频或旧配置打包给别人。

## 1. 设定角色 ID 和人设

角色 ID 只能用 2–40 位小写英文字母、数字、`_`、`-`，且首位必须是字母。例如 `mycharacter`。在 [`config/defaults.json`](../config/defaults.json) 把顶层字段改为：

```json
"character": "mycharacter"
```

复制 [`persona/kurisu.md`](../persona/kurisu.md) 为 `persona/mycharacter.md`，然后**全文重写**身份、性格、语气、禁忌。不要留下原角色的专有称呼或背景。当前对话解析和语音链路要求回复维持以下格式：

```text
【soft】
JP: こんにちは。
CN: 你好。
```

第一行只能使用 `src/core/emotion.mjs` 的 `EMOTIONS` 中的标签；`JP:` 是语音朗读文本，`CN:` 是面板显示文本。当前本地 Qwen 和阿里云语音请求都按**日语**配置；想把角色改为全中文或其他语言，单改人设不够，还须扩展回复解析与 TTS 语言参数，并做试听测试。

再复制 [`persona/kurisu.json`](../persona/kurisu.json) 为 `persona/mycharacter.json`，逐项改掉固定台词：

| 字段 | 出现场景 | 要求 |
| --- | --- | --- |
| `displayName` | 来电姓名、聊天输入提示 | 1–80 字符 |
| `callName` | 原生来电画面的 `Call from ...` 名称；不填则用 `displayName` | 可选，1–80 字符 |
| `welcome` | 新面板开场白 | `text`、`emotion` |
| `tapReactions` | 点击角色的短句 | 非空数组，每项 `text`、`emotion` |
| `taskLines.start/complete/failed` | Codex 任务播报 | 三组都非空，每项 `text`、`cn`、`emotion` |
| `callCanned`、`idleCanned` | 来电、闲聊生成失败时的兜底台词 | 两组都非空，每项 `jp`、`cn`、`emotion` |

这里的 `text` 和 `jp` 都是**角色会说出口的日语**，`cn` 是对应的中文。缺少文件或必填组时启动会报错，不会偷偷借用旧角色台词。`persona/*.md` 用于对话及主动生成，`persona/*.json` 用于固定台词与角色显示名，两个文件都要改。

## 2. 登记自己的 Live2D 模型

当前渲染器只支持 **Live2D Cubism 2**：模型入口是 `.model.json`，模型本体通常是 `.moc`。Cubism 3/4/5 的 `.model3.json` 不能直接替换；必须另行开发对应运行时与渲染器。

准备一个 `.tar.gz`，其中模型文件、贴图、动作和表情的相对路径必须与 `.model.json` 内引用一致。建议单层根目录：

```text
mycharacter/
  mycharacter.model.json
  model.moc
  textures/...
  motions/...
  expressions/...
```

例如文件夹已经位于 `D:\CharacterAssets\mycharacter`，可在安装有 `tar` 的 PowerShell 中制作归档并计算哈希：

```powershell
tar -czf D:\CharacterAssets\mycharacter.tar.gz -C D:\CharacterAssets mycharacter
(Get-Item D:\CharacterAssets\mycharacter.tar.gz).Length
(Get-FileHash D:\CharacterAssets\mycharacter.tar.gz -Algorithm SHA256).Hash
```

在 [`config/assets.registry.json`](../config/assets.registry.json) 的 `packs` 中，把原 `kind: "model"` 条目替换为自己的模型条目。原生面板使用项目虚拟环境中的 Cubism 2 库，无需另配 JavaScript 运行时素材。关键字段示例：

```json
{
  "id": "mycharacter-model",
  "kind": "model",
  "character": "mycharacter",
  "version": "1.0.0",
  "engine": "cubism2",
  "format": "tar.gz",
  "sizeBytes": 1234567,
  "sha256": "把上一步算出的 64 位 SHA256 填在这里",
  "stripRoot": "mycharacter",
  "entry": "mycharacter.model.json",
  "sources": [],
  "layout": { "scale": 1, "x": 0, "y": 0, "yRatio": 0.52 },
  "expressionMap": { "smile": ["happy", "excited"], "sad": ["sad"] },
  "motionMap": {
    "idle": { "group": "idle", "variants": 1 },
    "head": { "group": "tap_head", "variants": 2 },
    "body": { "group": "tap_body", "variants": 2 },
    "other": { "group": "idle", "variants": 1 }
  },
  "parameterMap": { "mouthOpenY": "PARAM_MOUTH_OPEN_Y" }
}
```

`sizeBytes` 必须是实际归档字节数，`sha256` 是实际归档的 SHA-256，不是模型 JSON 的哈希；复制示例占位值会安装失败。`stripRoot` 是归档最外层文件夹，`entry` 是去掉该层后的模型入口相对路径。`expressionMap` 的键要与模型的表情名称匹配，`motionMap.*.group` 与 `variants` 要与 `.model.json` 中的动作组和片段数量一致。没有对应动作组时可以不配置该动作，但点击时不会有该组动画。`parameterMap` 可按模型实际参数覆盖口型、视线、头部参数；未覆盖项使用默认 ID，若模型没有这些参数，相关微表情可能不生效。`layout` 负责缩放和居中，按实际模型调节。

`sources: []` 表示只做本地安装。若你拥有可合法分发的 HTTPS 下载地址，也可填写 `sources`；不要使用 `file://`，也不要把无授权模型放进公共发行包。修改同一模型包的归档内容后，重新计算哈希并提高 `version`，然后重新安装。

原生面板会读取上述 `layout` 与 `parameterMap`。`x`、`y` 以宽度 392 的参考显示区像素计，随窗口缩放；`yRatio` 默认 0.52，增大可下移角色。支持 `mouthOpenY`、`eyeBallX`、`eyeBallY`，以及显式覆盖的 `angleX`、`angleY`、`angleZ`、`bodyAngleX`。先确认模型确有相应参数，再逐项调整。点击优先使用 `head`、`mouth`、`body` 命中区域；若归档中的命中区域引用无效，原生面板检查实际透明像素并按显示区上下区分头部与身体，因此复杂模型应提供正确命中区域。

## 3. 在源文件中设定声线

在 [`config/defaults.json`](../config/defaults.json) 修改 `voice`，至少设 `enabled`、`provider`、`name`、`stability`。以下四种来源任选一种，不需要、也不应该在页面端为角色切换：

| `provider` | `name` 填什么 | 额外条件 |
| --- | --- | --- |
| `qwen-local` | 本地 Qwen TTS WebUI 已注册的克隆音色 ID | WebUI 与 Base 模型可用；`localModel` 与该服务实际模型一致 |
| `dashscope` | 当前阿里云百炼账号下**已复刻**的音色 ID | 自己配置语音 API Key；`dashscopeModel` 与音色兼容 |
| `edge` | Edge Neural 声线 ID，如 `ja-JP-NanamiNeural` | 这不是克隆音色 |
| `system` | 本机已安装的系统语音名称 | 这不是克隆音色；必须在目标电脑存在 |

本地克隆配置片段：

```json
"voice": {
  "enabled": true,
  "provider": "qwen-local",
  "name": "mycharacter_clone_01",
  "localModel": "Qwen/Qwen3-TTS-12Hz-0.6B-Base",
  "stability": true
}
```

这里只展示要改的字段，**不要用片段覆盖整个 `voice` 对象**；保留原文件其他设置。仅放入 WAV/MP3 样本并填写名称不会自动克隆；尚无音色 ID 的用户先按 [从零克隆教程](../使用教程.md#3-从零制作本地克隆音色) 在 WebUI 注册和试听。阿里云音色也须先在自己的账号复刻；本地 ID 与云端 ID 不能互换。密钥放环境变量或项目支持的本机加密密钥存储中，绝不能写进 `defaults.json` 或教程。`stability: true` 可防止所选克隆合成失败时静默换成另一种人声；失败会明确报错。来电**铃声**是独立提示音，可在本机数据目录 `sounds/incoming.wav` 设置，和角色声线无关。

## 4. 校验并让现有安装生效

编辑完成后，在项目目录执行：

```powershell
npm run character:check
npm run check
```

`character:check` 检查角色 ID、两个人设文件、Cubism 2 模型和语音默认值；`npm run check` 跑语法、测试和隐私扫描。**这两条命令不会切换正在运行的角色。**

首次安装还没有本机配置时，`defaults.json` 会自然生效。若这台电脑以前运行过 Amadeus，`%LOCALAPPDATA%\Amadeus\config.json` 会覆盖源码默认值；要应用新的角色和声线，先停服务再运行：

```powershell
node bin/amadeus.mjs stop
npm run character:apply
node bin/amadeus.mjs start
```

`character:apply` 只把源码中的 `character` 和主要语音选择写入**当前电脑**的配置，保留聊天、记忆、通知等其他设置；修改前会在同一数据目录备份原配置为 `config.json.backup-character-<时间戳>`。它不会上传密钥或克隆音频，也不会修改页面切换控件。若服务仍在运行，会拒绝应用；此时先确认停机。

将自己的模型归档安装到当前电脑（需先启动 daemon）：

```powershell
node bin/amadeus.mjs assets install-file mycharacter-model "D:\CharacterAssets\mycharacter.tar.gz"
node bin/amadeus.mjs assets status
node bin/amadeus.mjs assets verify
node bin/amadeus.mjs doctor
node bin/amadeus.mjs open
```

原生面板依赖若未安装，重新运行 `安装 Amadeus.cmd`。打开面板后，确认来电姓名与输入提示是新角色、Live2D 能显示且点击动作正确、开场白/聊天/任务播报/来电接听后的语音是所设声线。云端或本地克隆还需真人试听；通过自动测试不等于音色相似。

如果要分享定制版，运行 `npm run dist`，**只分享** `dist/` 中新生成的 ZIP，并检查人设、注册表链接及授权。模型归档、音色注册数据和 API Key 默认不会随项目 ZIP 走；接收者需自行安装有授权的模型与声线服务。不要直接压缩项目开发目录或本机数据目录。

## 常见问题

- **打开后还是旧角色**：确认改的是实际运行的插件副本；停止 daemon 后执行 `npm run character:apply`，再启动。若有多个 Amadeus 安装，检查正在启动的 `bin/amadeus-daemon.mjs` 路径。
- **人设变了，开场白或任务语音没变**：只改了 `.md`；同时修改同 ID 的 `.json`，重启 daemon 与面板。
- **模型成占位图**：检查 `character` 与模型条目的 `character` 相同、归档 `stripRoot/entry` 存在、SHA-256 匹配，以及原生面板依赖已安装；`.model3.json` 不受支持。
- **无声或音色不对**：确认 `voice.provider/name` 是对应服务里真正可调用的 ID、服务/密钥可用；克隆样本不是 ID。用 `doctor` 查具体降级原因，不要为消除报错而关闭 `stability`。
- **点击无动作或表情**：按模型自身 `.model.json` 核对动作组、片段数、表情名和参数 ID；示例映射不是通用名称。
- **想恢复原角色**：把 `defaults.json` 的 `character`、`voice`、注册表模型条目恢复为原值，保持原 `persona/kurisu.md/json`，然后重复停服务、`character:check`、`character:apply`、启动及原模型安装步骤。
